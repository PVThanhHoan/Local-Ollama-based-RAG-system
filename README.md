# Local-Ollama-based-RAG-system
## Requirements for local_rag_py:
- Python 3.14.3
- An IDE
- Docker Engine
- Libraries from requirements.txt
## How to install the program
Step 1: Install python and an IDE and Docker Engine

Step 2: Open up the Dockerfile in the IDE, create a docker image from the Dockerfile with command 1 from command_order.txt (make sure Docker is running in the background)

Step 3: Install Ollama models by running command 2,3,4,5 from command_order.txt in the command prompt

Step 4: Run created docker image with command 6 from command_order.txt in the command prompt 

Step 5: Run the program with command 7 from command_order.txt in the command prompt

##How to use
Step 1: Insert the pdf file

Step 2: Ask the program question and wait for answer
